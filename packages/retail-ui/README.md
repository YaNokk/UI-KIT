# @mypoint/retail-ui

Retail-композиции дизайн-системы MyPoint.

```tsx
import { QuantityInput } from "@mypoint/retail-ui";
import "@mypoint/ui/styles.css";
import "@mypoint/retail-ui/styles.css";
```

`@mypoint/ui`, React и ReactDOM являются peer dependencies. `QuantityInput`
использует только публичный UI package surface.
