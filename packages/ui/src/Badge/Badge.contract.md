# Badge contract

`Badge` показывает короткое строковое или числовое значение на solid
`SystemColor`-поверхности. Число сокращается до `max+` только при валидном
`max`; ноль не скрывается. Видимый текст доступен assistive technology, а
`label` при необходимости переопределяет accessible name. Размер фиксирован
контрактом v1 и не меняется автоматически на responsive breakpoints.
