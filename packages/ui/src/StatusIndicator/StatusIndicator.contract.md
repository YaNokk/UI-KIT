# StatusIndicator contract

`StatusIndicator` — компактная круглая цветовая точка для статуса. Размеры
`sm`/`md` являются приватно откалиброванной геометрией; цвет ограничен общим
`SystemColor`. Без `label` точка декоративна, с `label` имеет `role="img"` и
accessible name. Компонент не содержит текста или иконок и не меняет размер
автоматически на responsive breakpoints.
