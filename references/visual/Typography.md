# Typography visual reference

Source: extracted MP UI KIT direction documented by this repository.

## Validated compact scale

| Role | Size / line height | Weight |
|---|---:|---:|
| caption | 11 / 16 | 400 |
| bodySm | 13 / 18 | 400 |
| body | 14 / 20 | 400 |
| bodyStrong | 14 / 20 | 600 |
| bodyLg | 16 / 24 | 400 |
| headingSm | 16 / 24 | 600 |
| headingMd | 18 / 26 | 600 |
| headingLg | 22 / 30 | 600 |
| pageTitle | 28 / 36 | 600 |

The scale matches the repository's compact enterprise direction. No
letter-spacing adjustment was admitted: the current visual reference does not
show a repeated role that requires it.

Typography roles contain no color. Runtime brand may affect accent text and
links through separate semantic color tokens, never font metrics.
